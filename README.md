# Way8 Web & Legal Pages

Official web pages for **Way8** (operated by **Shangrao Tongtu Technology Co., Ltd.**):
- `index.html`: Product Landing Page
- `privacy.html`: Privacy Policy
- `support.html`: Support & Help Center
- `vercel.json`: Clean URL routing for Vercel

## Deployment
Configured for automatic deployment on [Vercel](https://vercel.com).
After connecting to Vercel, the pages will be accessible at:
- `https://<your-project>.vercel.app/`
- `https://<your-project>.vercel.app/privacy`
- `https://<your-project>.vercel.app/support`
